# Professional Portfolio

Static-first professional portfolio for Yeabsra Mekdim.

**Status:** v0.1.0 foundation candidate; not a released website.

## Development
Use Node.js 24 LTS (`nvm use`). Install dependencies with `npm ci` after the lockfile is committed; for initial lockfile generation only, use `npm install --package-lock-only --ignore-scripts`.
- `npm run dev` — local development.
- `npm run check` — Astro and TypeScript diagnostics.
- `npm run build` — static output in `dist/`.
- `npm run preview` — inspect built output.

Project Pages base path: `/professional-portfolio`. The custom domain and actual deployment are not authorized. No deployment workflow is enabled.

Read [AGENTS.md](AGENTS.md) and [project documentation](docs/PRODUCT_SPEC.md) before changing code or content. This repository is public; only publication-safe files may enter any branch or PR.
